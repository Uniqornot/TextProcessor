# ✨ Обработчик текста (TextProcessor)

**Быстрая очистка, нормализация и форматирование текста в один клик.**

Удобное настольное приложение для Windows, которое приводит «грязный» текст —
скопированный из чатов, PDF, нейросетей или веб-страниц — в аккуратный,
читаемый вид: убирает скрытые символы, Markdown-разметку, эмодзи, лишние
пробелы и переносы, нормализует тире и кавычки.

## 📖 О программе

**Обработчик текста** — это лёгкая WPF-программа для Windows, которая помогает
за секунды навести порядок в тексте. Слева вставляете исходный текст, выбираете
нужный инструмент — справа получаете чистый результат, готовый к копированию.

Особенно полезна при работе с текстом из нейросетей, мессенджеров, PDF и
веб-страниц. Программа удаляет невидимые Unicode-символы, Markdown
(`**жирный**`, `# заголовки`, списки и цитаты), эмодзи и лишние пробелы,
а также приводит кавычки, тире и многоточия к единому виду.

Обработка выполняется локально: текст не отправляется на сервер и не требует
подключения к интернету. Логика основной очистки согласована с
[AndroidTextCleaner](https://github.com/Uniqornot/AndroidTextCleaner), поэтому
на Windows и Android можно получить одинаковый результат.

## 🚀 Возможности

### 🧹 Инструменты обработки

| Инструмент | Что делает |
|---|---|
| ✨ **Полная очистка** | Конвейер AndroidTextCleaner: скрытые символы и Markdown → абзацы → кавычки, тире и многоточия → пробелы |
| ✂️ **Убрать пробелы** | Схлопывает повторяющиеся пробелы и табуляции, убирает пробелы по краям строк |
| 📄 **Одна строка** | Собирает весь текст в одну строку без переносов |
| ¶ **Исправить абзацы** | Приводит в порядок абзацы и убирает лишние пустые строки |
| **Умная нормализация** | Как в AndroidTextCleaner: `—`/`–` → `-`, фигурные кавычки → прямые, `...` → `…` |
| **Тире → дефис** | Выполняет только замену длинных тире `—`/`–` на обычный дефис `-` |
| **Кавычки → прямые** | Выполняет только замену `«ёлочек»`, `“лапок”` и других вариантов на `"` |
| 🛡 **Удаление скрытых символов** | Убирает невидимые Unicode-символы, Markdown-разметку, эмодзи и характерные ИИ-паттерны |
| ↵ **Управление переносами** | Нормализует переносы строк и структуру абзацев |

### 🧰 Дополнительно

- 🔒 **Локальная обработка** — введённый текст остаётся на компьютере.
- 📋 **Вставить / Копировать** — надёжная работа с буфером обмена (через нативный Win32 API; копирование срабатывает, даже если буфер занят менеджером буфера обмена).
- 📊 **Статистика** — подсчёт символов, слов, строк и абзацев для исходного и обработанного текста.
- ⚡ **Быстро и отзывчиво** — интерфейс не зависает даже на больших текстах.
- 🛟 **Устойчивость** — глобальный перехват ошибок: приложение не «падает» при неожиданных ситуациях.

## ✅ Пример

Исходный текст:

```text
> **«Новый текст»** — пример...
```

Результат полной очистки:

```text
"Новый текст" - пример…
```

Команды работают независимо: если требуется только убрать переносы, используйте
«Одна строка»; если нужно сохранить структуру текста и убрать лишние пустые
строки — «Исправить абзацы».

## 📥 Установка

1. Откройте страницу [**Releases**](https://github.com/Uniqornot/TextProcessor/releases/latest).
2. Скачайте файл **`TextProcessorSetup.msi`**.
3. Запустите установщик и следуйте инструкциям.

Приложение установится в `Program Files`, добавит ярлыки в меню «Пуск» и на
рабочий стол. Новые версии обновляются поверх старых автоматически.

> Требуется Windows 10 или 11 (x64). Дополнительно устанавливать .NET не нужно —
> приложение поставляется self-contained.

При установке новой версии поверх старой MSI выполнит обновление приложения.
Если одна из самых ранних сборок отображается отдельной записью, удалите её один
раз через «Параметры → Приложения», после чего последующие версии будут
обновляться штатно.

## 🛠 Сборка из исходников

Требования: [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```bash
# Клонировать репозиторий
git clone https://github.com/Uniqornot/TextProcessor.git
cd TextProcessor

# Запустить приложение
dotnet run --project TextProcessor/TextProcessor.csproj

# Собрать релизную версию
dotnet build TextProcessor/TextProcessor.csproj -c Release
```

### Сборка MSI-инсталлятора

Требуется [WiX Toolset v5](https://wixtoolset.org/) (`dotnet tool install --global wix`).

```powershell
cd TextProcessor
./build-msi.ps1
# Готовый пакет: dist/TextProcessorSetup.msi
```
